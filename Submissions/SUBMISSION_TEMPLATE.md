# InstaLite — Contribution Submission Template

Thank you for contributing to InstaLite! Please complete this template to document your contribution.

## Instructions

1. Create a new Markdown file inside the `Submissions/` folder.
2. Name the file using this format: `teamname-submission.md`, replacing `teamname` with your team name in lowercase. For example: `rubix-submission.md`.
3. Complete all the sections in the template below.
4. Create a new Git branch for your contribution and make your changes on that branch.
5. Submit your source-code changes through a **normal GitHub Pull Request** targeting the repository's appropriate base branch.
6. Include your completed submission Markdown file in the same Pull Request.

### Important submission rules

- **Only the submission report (`teamname-submission.md`) belongs inside the `Submissions/` folder.**
- Do not place source code, application files, screenshots, ZIP archives, or other project files inside `Submissions/`.
- Submit all code changes normally through your Pull Request, in their original project locations.
- Do not commit directly to the base branch.
- Use a descriptive branch name and commit messages.
- Make sure your submission report accurately describes your contribution.
